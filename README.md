## 📋 Description

A fully-featured VAT (Value Added Tax) calculator with a modern interface based on glassmorphism design principles. Supports both adding and extracting VAT for all Russian tax rates with real-time calculations.

### ✨ Key Features

- ✅ **Two calculation modes**: Add VAT and Extract VAT
- ✅ **Russian tax rates**: 20%, 10%, 0% + custom rate support
- ✅ **Real-time calculations** as you type
- ✅ **Dark mode** with localStorage persistence
- ✅ **Copy to clipboard** functionality
- ✅ **Fully responsive** design for all devices
- ✅ **Keyboard shortcuts** for power users
- ✅ **SEO optimized** with Schema.org markup
- ✅ **Accessibility compliant** (WCAG AA)
- ✅ **Zero dependencies** - pure vanilla JavaScript

## 🛠️ Technologies

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS variables, Grid, Flexbox
- **JavaScript (ES6+)** - Vanilla JS, no frameworks
- **Google Fonts** - Inter font family
